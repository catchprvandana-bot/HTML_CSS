Step 1

It starts with one neuron.

An artificial neuron takes a set of inputs, multiplies each by a learned weight, adds them up, and passes the result through an activation function that decides how strongly it "fires."

inputs × weights + bias activation function → output

Step 2

Layers stack into a network.

Thousands of these neurons are arranged in layers. Each layer learns slightly more abstract patterns than the one before it — edges, then shapes, then concepts.

InputHiddenHiddenOutput

Step 3

It learns by being wrong, a lot.

Every prediction is compared to the correct answer, producing a "loss" — a number that measures how wrong the model was. Backpropagation nudges every weight slightly to make that number smaller next time.
